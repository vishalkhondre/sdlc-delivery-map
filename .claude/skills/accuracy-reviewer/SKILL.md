# Accuracy Reviewer

1. Check cited mechanisms against the primary source, including conditions on approvals.
2. Follow a single candidate through code review, build, QA, UAT, deployment and recovery.
3. Challenge the diagram with manual assignment, configuration drift, unauthorized decisions and open requests.
4. Compare metric denominators, observation windows and claims of value. Distinguish evidence of delivery from a measured outcome.

## Return
