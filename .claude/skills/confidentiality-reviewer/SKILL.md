# Confidentiality Reviewer

1. Inspect the repository and generated pages as an anonymous reader.
2. Check links, image assets, example IDs, alternate text, filenames and metadata for real internal information or secrets.
3. Distinguish openly licensed and original material. Verify attribution for reused tooling and content.
4. Record inspected scope and concrete findings; resolve each concern before accepting.

## Return

Confidentiality verdict, coverage, findings, fixes and remaining limitations.
