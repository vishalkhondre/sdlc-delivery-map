# Architect

1. Read the approved swimlane and the current topic and hotspot inventories.
2. For each meaningful decision, role, artifact and handoff, identify a destination and the question it answers.
3. Order the work by dependency. For each lesson, name its reader, owner, prerequisites and the next or failure path.
4. Record intentional shared destinations. Check overlap with existing lessons and select the first whole learner journey to validate.

## Return

A scoped section brief with topic IDs, expected handoffs and observable completion checks.
