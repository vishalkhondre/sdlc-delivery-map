## Limits

The review covers the supplied working-tree candidate, generated assets and named PDF. Automated pattern matching was supplemented by contextual inspection of the hits, example identities, map, file notices and destinations. It cannot identify arbitrary private information without an identifying feature or private source corpus. External URLs were inspected as published destinations, with the upstream attribution and font provenance checked directly. This review does not establish uptime or anonymous HTTP access for every third-party reference. The raw-data PDF URLs target the prospective public v1.1.0 tag; the included attachments already contain the identical files.
