# Built site and navigation

The nine Prove pages are reachable from the qualification tour in inventory order, from their original map overview, and from the topic index. The parent breadcrumb and Next/Previous links serve different journeys. The first lesson links the downloadable evidence record. The final lesson hands off to rollout and smoke verification. The approved Build reading orders and the original map remain available.

The section build validated 80 lessons, 139 map regions, 13 search queries and 84 HTML pages. The nine reading paths and eight Kiwi disclosures were checked in generated HTML. Eleven unit tests passed. Browser automation also checks the entire Prove path and opens new deep dives at phone width. The local system browser could not open its startup socket. GitHub Actions runs the browser check and uploads the site for this integration PR; its final run is linked in the PR and gate report.
