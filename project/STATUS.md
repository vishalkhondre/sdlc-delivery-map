# Edition 1.0.0

The feature delivery reference contains 53 lessons, a seven-stop tour, a source index, 139 interactive map regions, a text alternative, and two fictional worked downloads. The release review covers the completed edition and records the corrections found in the three independent reviews.

To update an edition, change the learner source, rerun the checks, review the changed content and its affected links, and bind a new release record. The deployment workflow publishes the validated site from main. The tagged-release workflow produces the edition notes and printable section snapshot.
