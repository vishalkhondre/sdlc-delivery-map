# SDLC Delivery Map authoring instructions

Start with README.md, project/APPROACH.md, project/GROUND-RULES.md and project/AGENTS.md. Read the current edition and review before changing any public content. Use the repository’s existing public sources and the fictional approval-routing scenario. Keep the product decision, candidate identity, UAT sign-off, production authorization and outcome review distinct.

Follow project/DEPTH-PLAN.md and its owner amendments. The owner approves the depth inventory at Gate 1, reads the built CI pilot at Gate 2, and reviews each later section summary at Gate 3. Stop for the owner at each gate. Obtain Gate 4 approval before binding the combined edition.

Use the section pipeline for additions. Run the checks in README.md from the repository root. Record each observed review. Bind the exact authored edition at the approved release gate. Never record a review on another person's behalf.
